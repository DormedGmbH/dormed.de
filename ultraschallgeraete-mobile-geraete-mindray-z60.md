# Mindray Z60 — Mobiles Ultraschallgerät PSI+ Beam

SONORING DORMED ist autorisierter Mindray-Partner seit 2005 und bietet das Z60 mit vollständigem Service, Einweisung und Wartung an.

## Gerät auf einen Blick

- **Hersteller:** Mindray Medical, Shenzhen, China
- **Modell:** Z60
- **Gerätetyp:** Mobiles Laptop-Ultraschallsystem Mittelklasse
- **Plattform:** PSI+ Beam
- **Monitor:** 13,3 Zoll + externer Anschluss
- **Schallkopfanschlüsse:** 4 aktive Ports
- **Akkubetrieb:** Optional
- **Elastographie:** Optional verfügbar
- **Zertifizierung:** CE, EU MDR

## Technische Features

- **Smart Beam:** Automatische Bildoptimierung
- **Farbdoppler:** Vollständig — Farbdoppler, PW-Doppler, Power Doppler
- **Elastographie:** Optional hinzubuchbar
- Externer Monitoranschluss für größere Bilddarstellung

## Klinische Anwendungsgebiete

Allgemeinmedizin, Innere Medizin, Abdomen, Schilddrüse, Gefäße, Gynäkologie
